# DiNho Optimizer — Funcionalidades AUSENTES (Consolidadas de 20 Repositórios)

## 🏆 PRIORIDADE MÁXIMA (Alto Valor, Diferenciador)

### 1. Remoção de Bloatware / Apps UWP
- Desinstalar apps pré-instaladas da Windows Store (Candy Crush, Xbox, Copilot, OneDrive, etc.)
- Impedir reinstalação via Appx deprovisionamento + políticas ContentDeliveryManager
- Lista de permissão/bloqueio por app com UI de seleção categorizada
- Bloquear apps Microsoft específicas: Novo Outlook, Phone Link, Edge, anexos OneNote
- Remover Microsoft Copilot completamente + desabilitar Windows Recall
- Desabilitar recursos de IA no Windows, Paint, Bloco de Notas, Edge, WSAIFabricSvc
- Repos: Win11Debloat, BloatyNosy, Sophia-Script, Win-Debloat-Tools, Winscript, UnattendedWinstall, Windows10Debloater, privacy.sexy

### 2. Integração com Gerenciadores de Pacotes (Winget/Chocolatey/Scoop)
- Navegar, instalar, atualizar e remover apps via Winget, Chocolatey e Scoop
- Coleções de apps curadas (Dev, Navegadores, Utilitários, Gaming, etc.)
- Operações em lote/fila com acompanhamento de progresso
- Atualização automatizada diária de pacotes via tarefa agendada
- Instalação com um clique de VC++ Redistributáveis, DirectX, .NET SDKs, WSL
- Repos: Win-Debloat-Tools, BloatyNosy, Winrift, WinKit, TidyWindow, winscript

### 3. Suite de Endurecimento de Segurança
- Regras ASR (Attack Surface Reduction) — gerenciamento de 14+ regras (processos Office, LSASS, ransomware, USB, WMI, etc.)
- Device Guard / Credential Guard (VBS, isolamento em nível de hypervisor)
- Windows Defender Application Control (WDAC) com mecanismo de simulação
- Políticas de lista de permissão AppLocker
- Proteção LSA (RunAsPPL) contra roubo de credenciais
- Configuração de mitigação de exploração (CFG, DEP, ASLR, SEHOP, integridade heap)
- Endurecimento TLS/SSL (desabilitar 1.0/1.1, cifras fracas, habilitar 1.3)
- Endurecimento SMB (desabilitar SMB1, forçar assinatura/criptografia, versão mínima)
- Gerenciamento BitLocker (ativar/configurar, algoritmos de criptografia, protetores de chave, TPM)
- Repos: Harden-Windows-Security, HardeningKitty, Windows-Optimize-Harden-Debloat, hardentools, privacy.sexy

### 4. Auditoria de Conformidade & Pontuação
- Auditar sistema contra CIS Benchmarks, DoD STIG, BSI SiSyPHuS, MS Security Baselines
- Pontuação de postura de segurança (1-6) com resultados categorizados de aprovado/reprovado
- Aplicar Microsoft Security Compliance Toolkit (700+ configurações de Política de Grupo)
- Configuração avançada de política de auditoria (logon/logoff, acesso a objetos, uso de privilégios)
- Gerar relatórios de auditoria de desbloat (antes/depois)
- Detecção de desvio (Drift) — comparar estado atual do registro contra JSON de estado desejado
- Repos: HardeningKitty, Windows-Optimize-Harden-Debloat, Win-Debloat-Tools, Winrift

### 5. Gerenciador de Recursos/Capacidades do Windows
- Ativar/desativar componentes opcionais do Windows (Hyper-V, WSL, .NET Framework, Recursos de Mídia, SMB, Windows Sandbox)
- Instalar/desinstalar Features on Demand (Servidor OpenSSH, RSAT, etc.)
- Ativar .NET Framework 3.5 da mídia de instalação sem internet
- Repos: RyTuneX, Sophia-Script, Win11Debloat, UnattendedWinstall
