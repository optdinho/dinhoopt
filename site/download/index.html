PASSO A PASSO

Como instalar em 3 passos

O instalador pede permissão de administrador — é normal: o app precisa dela para limpar, reparar e otimizar o Windows.

01

Baixe o instalador

Clique em Baixar instalador. O arquivo .exe tem cerca de 240 MB.

02

Execute e autorize

Abra o arquivo baixado e aceite o pedido de administrador do Windows (UAC).

03

Ative a licença

O app abre já instalado. Insira sua chave ou escolha um plano para liberar todos os recursos.

DÚVIDAS

Perguntas frequentes

O essencial antes de baixar.

O download é gratuito?

Sim. Baixar e instalar é gratuito. Para usar todos os recursos (limpeza, otimização, Game Mode, Clipe de Jogos) é preciso uma licença — veja os planos.

Qual a diferença entre o instalador e o portable?

O instalador registra o app no Windows, cria atalhos e permite desinstalar pelo Painel de Controle. O portable é um único arquivo que roda sem instalar nada — útil para testar ou levar num pen drive. Ambos têm as mesmas funções.

Por que o instalador pede permissão de administrador?

Porque o DiNho Optimizer altera configurações do sistema: limpeza de arquivos, registro, serviços, drivers e ajustes de desempenho. Sem privilégios elevados, essas operações seriam bloqueadas pelo Windows.

O Windows vai acusar o arquivo como suspeito?

Pode acontecer com instaladores novos que ainda não acumularam reputação no SmartScreen. O arquivo vem direto das releases oficiais deste repositório; se preferir conferir, o GitHub exibe o tamanho e o hash de cada asset.

Como recebo as atualizações?

O próprio app verifica e instala atualizações automaticamente. Esta página também mostra sempre a versão mais recente publicada, então voltar aqui é a forma mais simples de baixar de novo.

Funciona no Windows 7 ou 8?

Não. O app é feito para Windows 10 (build 19041 ou superior) e Windows 11, 64-bit.
